# Geometry-controlled correlated electric-field noise in enclosed ion traps from billiard return spectra

**Status:** public arXiv preprint  
**Author:** Ayush Nadiger  
**arXiv:** [2608.24770](https://arxiv.org/abs/2608.24770) — v1 submitted 25 August 2026  
**DOI:** https://doi.org/10.48550/arXiv.2608.24770  
**Subjects:** quant-ph; physics.atom-ph  
**Length:** 15 pages, 10 figures

This directory records the canonical public version of my undergraduate honors-thesis paper. The manuscript studies how passive conducting geometry reshapes correlated electric-field noise in trapped-ion systems, from the full multi-ion covariance/Kossakowski description to exact parallel-slab results, collective noise channels, gate exposure, and curved-boundary billiard diagnostics.

## Canonical manuscript

Use the arXiv v1 record above as the source of truth for the posted manuscript. I have intentionally not copied an older pre-arXiv working draft into this directory under the name of the submitted version.

## Reproducibility

Code, frozen numerical outputs, and verification scripts are maintained in the public repository:

- https://github.com/ayushnadiger/noise_recycling

The independent verifier is `verify_pra_results_final.py` in that repository.
